easel is MIT-licensed (see [LICENSE](LICENSE)). This file names the software easel depends on or drives and the
licence each one declares. It is a record for users and contributors, not legal advice: each project's own
licence text is the authority.

## Python packages pip installs with easel

None of these is copied into this repository; pip installs them from their own releases. The tables are
generated by `tools/gen_notices.py` from the installed packages' metadata (through `pip-licenses`), so the
licence strings are the ones each package declares. Regenerate them in the same pull request that changes a
dependency. CI's licence gate refuses any installed package whose licence string is not on the reviewed list in
`.github/workflows/ci.yml`; `tests/test_licence_gate.py` proves that it does.

## Programs easel drives but does not include

easel talks to these over ComfyUI's HTTP API only. It never imports, vendors or copies their code; you install
them yourself at the commits pinned in [runtime/comfyui.lock.json](runtime/comfyui.lock.json), which also
records the licence read from each project's LICENSE file and the date it was read.

- **ComfyUI** (GPL-3.0): the renderer every recipe runs on.
- **ComfyUI-Impact-Pack** (GPL-3.0): the face detailer nodes. Only the detailer workflow needs it; without the
  pack that workflow is unavailable and everything else works.
- **ComfyUI-Impact-Subpack** (AGPL-3.0): the detector provider the detailer uses. It installs **ultralytics**
  (AGPL-3.0) into your ComfyUI environment, never into easel's. The duties of AGPL-3.0 section 13 fall on
  whoever offers that ComfyUI to other people over a network; easel itself neither imports ultralytics nor
  runs it.
- **Other node packs**: each one is listed in `runtime/comfyui.lock.json` with the licence read from its
  LICENSE at install time, and counts as `unverified` until someone has read it (`easel doctor` says so).

## Services easel can read

`easel search` and `registry download` read the public Civitai API (`/api/v1/` and `/api/download/` only) and
the Hugging Face API, under those services' own terms. Nothing they return is shipped in this repository, and
every model keeps its own licence, recorded per resource in your instance (`licence:` in the resource file).

## Data that is not shipped

- No model weights, images or datasets are included. Test images are generated at test time.
- The content-marker term lists (`data/content_markers.yaml`) are hand-written and generic; no third-party
  term list is shipped, so none needs a notice here.

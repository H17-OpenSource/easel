# Lessons: publishing from a private project without leaking it

These lessons come from preparing this repository for publication in 2026-11, when it was rewritten out of a
private working setup. They are for anyone who turns their own tooling into a public project, and for the
maintainers' sweep before each release. Every rule here is enforced somewhere (the last column); a rule that
nothing enforces belongs in an issue, not on this page.

| # | finding | evidence | rule | recorded in |
|---|---|---|---|---|
| 1 | A copied file brings its past with it. | The private sources kept private values in self-tests, constants and docstrings, often in the very code that guarded them. | Port, never copy: read the old file while writing the new one, and check new files for near-copies of old ones before publishing. | CONTRIBUTING.md, "Contribution terms" |
| 2 | Values hide behind encodings that a plain text search misses. | Ordinary tools produce each form: JSON writers double backslashes, file URLs percent-encode spaces, some Windows tools write UTF-16, APIs nest JSON inside strings. | The scanner decodes every form before matching: UTF-8 and UTF-16, repeated JSON unescaping, URL decoding, NFKC and casefolding. | `src/easel/_common/privacy.py` |
| 3 | Images and model files carry metadata. | ComfyUI writes the whole workflow, prompts included, into PNG text chunks; safetensors headers hold free-form metadata that trainers fill with paths and settings. | Never commit media or weights; generate test images at test time into an ignored folder; the scanner reads PNG text chunks and safetensors headers, and the pre-push gate refuses any binary file. | `.gitignore`, `tools/pre-push-gate` |
| 4 | A lock file written from a live environment records the machine. | Freezing an environment that holds an editable install writes a `@ file:` line naming a local folder. | Pin lock files by hand from recorded versions; never generate them from an existing environment. | `runtime/`, the `pip-file-reference` pattern |
| 5 | Shapes can be published; values cannot. | A pattern for "a drive path" is harmless in public, while a list of the actual names, folders and ports is a concentrated record of everything it protects. | Ship structural patterns only; keep the values in a private list outside every repository and every synced or backed-up folder; print counts, never the matched text. | `data/privacy/private-words.example.txt` |
| 6 | A test that asserts a value is absent puts the value in the test. | A proposed test that a folder name never appears would have published that folder name in its own source. | Build hazardous needles at run time from fragments or synthetic values; the scan reads `tests/` with no allowlist. | `tests/common/test_privacy.py`, `tests/test_pre_push_gate.py` |
| 7 | Dates and ids reveal a timeline. | Ids carry their creation date (`run-YYYYMMDD-<slug>`), so one real id in an example dates the work. | Fixtures and documented output use a frozen clock in 2030 and demo ids; real-year id shapes are public patterns. | `examples/demo/`, the `real-year-id` pattern |
| 8 | History and identity are part of what you publish. | A value removed in the last commit is still in every earlier one; a machine's global git identity carried a personal e-mail address that every commit would have published; and every commit records the committer's local UTC offset, which tells where they live and when they work. | Publish a fresh-history snapshot; set the repository's commit identity before the first commit and use a noreply address; commit in UTC (`TZ=UTC`, or `GIT_AUTHOR_DATE` and `GIT_COMMITTER_DATE` ending in `+0000`). The gate checks each pushed commit's identity and refuses an offset other than `+0000`. | `tools/pre-push-gate`, `tools/install-hooks.py` |
| 9 | Host facts are private even when they look technical. | A non-default server port and a numbered folder layout belong to one machine; the public default port belongs to everyone. | Only public defaults ship (ComfyUI's `127.0.0.1:8188`, allowlisted with a reason); host ports and folder names go on the private list; the shipped pattern covers the numbered-folder shape only. | `data/privacy/allow.yaml`, the `numbered-folder` pattern |
| 10 | Docs pick up output from real runs. | Captured command output would have carried the frozen-clock warning until the warning moved to stderr; pasted output carries absolute paths and real dates. | Generate documented output from the demo under the frozen clock with `--redact-paths`, stdout only; `qa docs` rejects the clock warning in an output block. | `docs/runbooks/README.md`, `easel qa docs` |
| 11 | An exception applies wherever its text appears. | An entry that excuses a text everywhere also excuses it in places nobody reviewed. | Each allowlist entry carries a reason a reviewer can check and is narrowed by path or pattern where it can be; nothing under `tests/` is ever excused; never loosen a pattern to make a scan pass. | `data/privacy/allow.yaml` |
| 12 | A scan that cannot read its list must not pass. | Without a check, a missing private list turns a full scan into a public-only scan that still reports clean. | The scanner and the gate fail closed: exit 2, and the push is refused, when a list cannot be read. | `tools/pre-push-gate`, `src/easel/_common/privacy.py` |
| 13 | The private list is never finished. | Every new run, upload or reference record adds ids the list did not have the day before. | Refresh the list from your own data before every publish (`privacy scan --harvest-sql` runs your own SELECT statements); a scan counts as clean only against a fresh list. | `easel privacy scan --help` |
| 14 | Tools are not the last check. | A scanner finds only what its lists name; a value nobody listed passes it. | Before the first push a person reads the top-level documents in full and a random sample of the rest, and spot-checks a few private words with `git grep -i`. | the maintainers' release checklist |
